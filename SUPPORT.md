# Support

This project is maintained by Dynatrace. For product support, use the applicable Dynatrace support channel. GitHub Issues may be used for repository-specific bugs, feature requests, and contribution discussions as described in this repository.

## Getting help

- **Product support**: use the applicable [Dynatrace support channel](https://support.dynatrace.com) for questions about the Dynatrace platform itself (tenants, licensing, API behavior outside this tool).
- **Bugs and feature requests**: [open a GitHub issue](../../issues/new). Please include the `dtctl version` output, the command you ran, and the (redacted) error message.
- **Contributing**: see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Security vulnerabilities**: do not use public issues. Follow [SECURITY.md](SECURITY.md).

## Stability

Some commands and flags are `experimental` or `development` tier and may change or be removed. See [docs/STABILITY.md](docs/STABILITY.md) for what each tier promises.
